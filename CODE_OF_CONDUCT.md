# Código de conducta

LupaBin es un proyecto educativo. Participa con respeto, paciencia y disposición a corregir errores.

- Critica ideas y código, no a las personas.
- Distingue hechos comprobados de hipótesis; corregir una afirmación es parte del aprendizaje.
- Ayuda a quienes empiezan y evita descalificaciones, acoso o discriminación.
- Respeta la privacidad: no publiques datos personales, credenciales ni muestras reales.
- No uses el proyecto para intimidar o perjudicar a terceros.

Los responsables pueden pedir cambios, retirar contenido o restringir la participación ante incumplimientos. Comunica incidentes por un canal privado acordado con el responsable; no publiques información sensible para denunciar un problema.
